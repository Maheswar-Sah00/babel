How it works

A plan you can check, step by step

  1. 1

    Find games like yours

    A new game has no fan data yet, so Babel finds well-known games that share your Steam tags (rare tags count more). Qloo must have real fan data for each one.

  2. 2

    See where their fans are

    Babel starts from what English-only indie games usually see, then uses Qloo's fan maps to lean toward the languages that fans of games like yours speak.

  3. 3

    Fit your budget

    Babel picks the best mix that fits your budget: full translations first, then store pages. Babel's code works out every number; an LLM only reads descriptions and explains the plan.
